# Entwicklungswerkzeuge

Dieser Ordner ist für kleine, reproduzierbare Hilfswerkzeuge reserviert, etwa für spätere Datenanalysen oder Migrationsprüfungen.

Produktive oder dauerhaft eingecheckte Skripte zur EDWALT-Migration dürfen erst
entstehen, wenn Satzlayouts, Schlüssel, Beziehungen, Migrationsumfang und das
fachliche Zielmodell verstanden und dokumentiert sind. Ein datensparsamer
Analyseprototyp existiert bis dahin ausschließlich im geschützten lokalen
Arbeitsbereich außerhalb des Repositories; siehe
`docs/migration/edwalt-extraction-prototype.md`. EDWALT wird nicht 1:1
nachgebaut; Werkzeuge dürfen keine echten Verwaltungsdaten, vollständigen
Extrakte oder Zugangsdaten enthalten.
