# Schritt 00 – Sessionablauf vorbereitet

Datum: 19.10.2026.

## Ergebnis

Der Auftrag ist als funktionale 1:1-Portierung von Sunrise nach Cemaris mit
Python, React und Microsoft SQL Server dokumentiert. Branding gehört dazu.
Die Portierung ist in 16 nacheinander auszuführende Implementierungsschritte
aufgeteilt. Jede neue Session erhält ihren Auftrag aus STATUS.md und PLAN.md.

Angelegt wurden die Cemaris-README, AGENTS.md, PLAN.md, STATUS.md und ein
wiederverwendbarer Startprompt. Die zentrale README im übergeordneten
Verzeichnis wurde auf die aktuelle Entscheidung umgestellt.

## Geprüfte Ausgangslage

- Sunrise-Arbeitskopie unverändert am Commit
  `451ce034863b16502484367044f3e9b65370111a`.
- Paketversion `1.0.0-beta.21`.
- Statisch erfasst: 41 Tabellen im Initialisierungscode, 11 Routendateien,
  221 Handlerdateien und 64 EJS-Ansichten.
- Vorhandene Quelltests und externe Integrationen sind im Schrittplan
  berücksichtigt.
- Vor Beginn dieser Vorbereitung enthielt Cemaris nur seine neue Git-Historie.

Die lokalen Markdown-Verweise sowie die Nummerierung von Plan und Status
wurden bei der Vorbereitung geprüft. Anwendungstests wurden nicht ausgeführt,
weil dieser Schritt ausschließlich den Ablauf vorbereitet. Die Anwendung,
das SQL-Server-Schema und Docker-Dateien werden ab Schritt 01 erstellt.
